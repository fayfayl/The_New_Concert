The New Concert

The New Concert is an in-development game. Currently, there is no game to speak of so have fun looking at an incomplete map.

Changelog

Indev v0.8.b 21 Oct 2026

  • All polities now have a government, with laws, national spirits, etc.
  • All populated provinces now have ideological support.
  • More flags added, though some still use the placeholder flag.
  • Overhauled the UI to look like paper, with some radio buttons I guess.
  • Puppets now appear in the diplomacy panel's relations.
  • Tooltip local time now shows whether it is day, twilight or night.
  • Added console commands for changing laws, government forms, doctrines, policies, decrees and national spirits, and for setting infrastructure levels, factories, forts and rail.

Indev v0.8.a 30 Sep 2026

  • Added country information/diplomacy panels.
  • Added already existing flags to countries, some still have placeholders right now.
  • Added laws and national spirits to some countries, still work in progress. Sakan, Meridon, Telmanland, and Therundia are done. Panathra is ongoing.
  • Some national spirits have custom icons: Krenland, Twadamia, Subeny, and Kaganland.
  • Laws have custom icons, but not doctrines yet.
  • Overhauled forts so they now work on the county level.
  • Added "Controls" button to see controls in-game.
  • Added "Ideology" layer where each province's ideological popularity/make up is shown.

Indev v0.8 1 Sep 2026

  • Added a barebones Happiness and unrest mechanic on the user interface.
  • Added max slots and levels for provincial infrastructure.
  • Added all starting infrastructures in provinces, including the levels and factory slots themselves as well as eyries, dockyards, and 1 synthetic rubber plant.

Indev v0.7 21 Aug 2026

  • Non-placeholder name finally decided on: The New Concert.
  • The map is now finished in terms of both cities and countries.
  • Added a secondary level of division below provinces: counties.
  • Added sea subdivisions.
  • Added rivers.
  • Overhauled terrain so the map now shows both climate and terrain.
  • Added sound effects for button clicks and for selecting provinces and regions.
  • The day-night divide is now a working cycle.
  • Added resources and their icons.
  • Started adding population to provinces. Therundia is finished, Sakan is ongoing.

Indev v0.6 17 Aug 2026

  • Finished Sakan, Vaseta, and most of Keronsar in terms of countries.
  • Added all Sakanese cities, and half of Panathran cities.
  • Added barebones version of 'occupation and core territories' mechanic so Vosennac now actually occupies part of Cunaria, and the Fuinamese Civil War now looks like a war.
  • Added new start menu background image.
  • Added loading screen with quotes from in-universe figures.
  • Added barebones day-night divide with no way to move forward currently.

Indev v0.5 15 Aug 2026

  • Finished Sakan in terms of countries.
  • Added all cities to Meridon.
  • Half of Sakan now has cities.
  • Added the first few countries to Panathra.
  • Reworked city labels a bit so they now try to avoid country labels.
  • Added Changelog and About tabs in the start menu.
  • Changed main font to Cabin.

Indev v0.4 12 Aug 2026

  • Sakan is almost finished in terms of countries.
  • Added info panel for provinces (no info yet because I'm not doing statistics and game mechanics at the moment).
  • Adopted Gill Sans MT as the main font.

Indev v0.3.a 10 Aug 2026

  • Fixed typo in start menu.

Indev v0.3 10 Aug 2026

  • Added several more countries in Sakan.
  • Gave UI texture.
  • Overhauled country label generation system so it stops lagging so much.
  • Added more cities.

Indev v0.2 9 Aug 2026

  • Added a few more countries to the map
  • Added bare-bones menu screen

Indev v0.1 9 Aug 2026

The first formal release. Nothing is playable, have fun looking at an incomplete map.
